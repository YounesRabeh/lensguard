# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of LensGuard and the
current `main` branch. Please upgrade before reporting an issue that may have
already been fixed.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Instead, use [GitHub's private vulnerability reporting](https://github.com/YounesRabeh/lensguard/security/advisories/new).

Include a clear description of the issue, affected versions, steps to
reproduce it, and any suggested mitigation. If possible, include a minimal
proof of concept that does not expose sensitive data.

You can expect an acknowledgement within 7 days. We will investigate the
report, coordinate a fix and disclosure timeline with you, and credit you in
the advisory unless you prefer to remain anonymous.
